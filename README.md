# TH3V151T0R5_PT

마스토돈 기반 THE VISITORS 커뮤니티 자동봇.
멘션 명령어를 받아 출석, 수업, 아르바이트, 카피캣 돌보기 등을 처리하고 Google 스프레드시트에 결과를 기록합니다.

---

## 파일 구조

```
main.rb                         진입점. 15초마다 멘션 폴링
mastodon_client.rb              마스토돈 API 래퍼
sheet_manager.rb                Google Sheets 읽기/쓰기
command_parser.rb               명령어 분기
commands/
  register_command.rb           [등록/캐릭터명]
  status_command.rb             [상태]
  attendance_command.rb         [출석]
  activity_command.rb           [수업/이름] [아르바이트/이름] [클럽/이름]
  cat_register_command.rb       [카피캣등록/이름]
  feed_cat_command.rb           [먹이/음식명]
  cat_status_command.rb         [카피캣]
  observe_cat_command.rb        [관찰]
  colony_command.rb             [군체확인] [카피캣랭킹]
  progress_command.rb           [진행참여]
  toot_settlement_command.rb    [툿정산/숫자]
utils/
  date_helper.rb                요일 판별
  result_judge.rb               성공 판정
  korean_particle.rb            조사 처리
```

## 설치 및 실행

```bash

pm2 start main.rb --name visitors_pt --interpreter ruby

```

## 성공률 계산식

```
성공률 = 50 + 관련스탯1×2 + 관련스탯2×2 + 행운×1 - 난이도
최소 20% / 최대 90%
```

판정 결과:

| 결과 | 조건 |
|------|------|
| 대실패 | 주사위 1~5 |
| 실패 | 주사위 > 성공률 |
| 성공 | 성공률 이하 |
| 대성공 | 성공률 이하 + 주사위 낮을 때 |

배율은 활동 시트 I~L열에서 읽습니다.
